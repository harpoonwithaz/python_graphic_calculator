# Turtle Graphing Calculator

## Description

A graphing calculator built with Python's turtle graphics module. Choose between graphing sine waves or linear functions with customizable parameters like amplitude, period, slope, and shifts.

## How It Works

1. Select a mode: Sine graph or Linear function
2. Configure viewport settings (screen size and zoom level)
3. Enter function parameters (use default values by pressing Enter)
4. The graph is drawn on a grid in a new window
5. Click anywhere on the window to close it

## Installation & Running

### Requirements

- Python 3.x
- turtle module (included with Python)
- math module (included with Python)

### Steps

1. Clone or download this repository
2. Open a terminal/command prompt in the project directory
3. Run: `python turtle_graphing_calculator.py`
4. Follow the prompts in the terminal to configure and graph your function
